Всем привет, наша команда из 3 человек разработала мини проект-тренажер, который поможет вам потренировать написание кода на с++.
Вы запускаете код, вам выдается случайная строка из с++, которая может пригодиться вам при решении задач. Вы должны переписать эту строчку.
Когда вы ее перепишите, вам выдаст результат: за сколько времени вы ее переписали (если время будет превышать 24 часа, оно сбрасывается, то есть учитывает только количество часов, минут и секунд) и сколько ошибок допустили при написании.
